Arquitectura & Optimización de Recursos
Desarrollo de una aplicación escalable y paquete reutilizable utilizando Clean Architecture y BLoC. El impacto principal fue la optimización del consumo de APIs para rutas de múltiples destinos y la implementación de almacenamiento local de alto rendimiento para persistir la información del cliente, garantizando disponibilidad inmediata.

Eficiencia y Reducción de Costos

En lugar de hacer peticiones a Google Places cada vez que el usuario navega por la app, implementé una capa de repositorio inteligente.

  • Búsqueda Personalizada: Algoritmo de filtrado que va más allá de las categorías por defecto de Google.
  • Reducción de Peticiones: Caché de rutas multidestino gestionado por BLoC para evitar llamadas redundantes a la red.
  • Persistencia Local: Uso de base de datos local para guardar clientes y lugares frecuentes, permitiendo acceso offline y carga instantánea.
